Background & Problem
배경과 문제
교육운영1팀이 직면한 이메일 처리 한계와 그로 인한 운영 리스크를 정의합니다.
하루 50건 이상의 HR 이메일이 수신되지만,
분류·답변·추적까지 모든 과정이 수동으로 처리되고 있습니다.
P1
체계적인 분류 수단 부재
신청·변경·취소 이메일이 혼재되어 수신되지만 별도 분류 없이 운영대표가 하나씩 열람·판단해야 합니다. 처리 누락이 발생해도 즉시 인지하기 어렵습니다.
Critical
P2
반복 답변으로 인한 시간 낭비
동일한 내용의 답변을 매번 작성합니다. 교육 신청 접수 안내, 변경 확인 안내 등 정형화된 답변에도 전체 작성 시간이 소요됩니다.
High
P3
처리 지연으로 인한 HR 담당자 컴플레인
이메일 처리가 늦어지면 HR 담당자가 교육 일정 확인을 위해 재문의하거나 불만을 제기합니다. 이는 고객 신뢰도에 직접적인 영향을 미칩니다.
High
P4
단일 장애점 구조
운영대표 부재 시 이메일 확인·답변이 전면 중단됩니다. 백업 담당자가 없거나, 인수인계 없이 처리 현황 파악이 어려운 구조입니다.
Medium

04
Feature Specification
기능 명세
MVP 범위 내 3개 핵심 기능의 요구사항과 사용자 시나리오를 정의합니다.
F1
Must Have
이메일 자동 분류
수신 이메일 50건 이상을 운영대표가 하나씩 열어 유형을 판단하는 현재 방식은 처리 속도를 저하시키고 누락 위험을 높입니다. 자동 분류로 판단 시간을 제거하고 즉시 처리 가능한 상태로 전달합니다.
요구사항
수신 이메일을 교육 신청 / 교육 변경 / 교육 취소 / 기타 4가지 유형으로 자동 분류
제목 및 본문 키워드 기반 분류, 분류 신뢰도 수치 함께 표시
신뢰도 70% 미만 이메일은 "검토 필요"로 별도 표시
운영대표가 분류 결과를 드롭다운으로 수동 수정 가능
설정 화면에서 유형별 키워드 추가·삭제 가능
사용자 시나리오
01
운영대표가 메일 가져오기 버튼 클릭
02
시스템이 그룹웨어에서 이메일을 수집하고 유형별로 자동 분류
03
수신함에 유형 뱃지·신뢰도가 표시되고, 검토 필요 건은 별도 탭으로 분리
04
운영대표가 잘못 분류된 건을 드롭다운으로 수정
F2
Must Have
반복 유형 자동 답변
교육 신청·변경·취소에 대한 답변은 90% 이상이 동일한 형식입니다. 매번 수작업으로 작성하는 대신 사전 정의된 템플릿으로 즉시 발송하여 응답 시간을 단축하고 운영대표의 반복 업무를 제거합니다.
요구사항
교육 신청·변경·취소 유형별 답변 템플릿 사전 설정 및 자동 적용
{{이름}}, {{교육명}} 등 변수 치환으로 개인화된 답변 생성
발송 전 운영대표 검토 모드 / 즉시 발송 모드 선택 가능
발송 전 미리보기 팝업에서 내용 직접 수정 가능
자동 답변 발송 이력 로그 관리 (7일 보관)
그룹웨어(다우기술)와 연동하여 실제 이메일 발송
사용자 시나리오
01
분류된 이메일에서 답변 대기열로 이동 클릭
02
유형에 맞는 템플릿이 자동 적용된 미리보기 표시
03
운영대표가 내용 확인 후 발송 승인 또는 내용 수정
04
그룹웨어를 통해 실제 이메일 발송, 상태 "답변완료"로 변경
F3
Should Have
처리 현황 대시보드
현재는 미처리 이메일이 몇 건인지, 어떤 유형이 많은지 파악할 방법이 없습니다. 처리 현황을 실시간으로 시각화하면 업무 우선순위 판단과 팀 성과 측정이 가능해집니다.
요구사항
미처리 건수, 당일 처리율, 자동 분류율, 답변 완료 건수 KPI 카드
유형별(신청·변경·취소·기타) 수신량 바 차트
HR 담당자별 요청 현황 집계 (상위 5명)
주간 수신량 추이 그래프
최근 처리 활동 피드 (답변 발송, 검토 필요 알림 등)
사용자 시나리오
01
운영대표가 오전 업무 시작 시 대시보드 확인
02
미처리 건수와 유형별 현황을 한눈에 파악
03
취소 유형이 많으면 해당 탭으로 이동해 우선 처리
04
주간 추이로 업무량 패턴 파악 및 팀 리포팅 활용
05
Scope
범위 정의
MVP 포함 범위와 제외 범위를 명확히 정의하여 개발 범위를 통제합니다.
포함 (In Scope)
다우기술 그룹웨어 이메일 수집 및 분류
교육 신청·변경·취소 유형 자동 분류
유형별 답변 템플릿 자동 생성 및 발송
발송 전 운영대표 검토 기능
처리 현황 실시간 대시보드
발송 이력 로그 관리
분류 규칙 및 템플릿 설정 관리
제외 (Out of Scope)
그룹웨어 외 타 이메일 시스템 연동
HR 시스템(인사 DB) 직접 연동
챗봇·전화 채널 확장
다국어 처리
모바일 앱 개발
일/주/월 단위 리포트 자동 생성 (추후 검토)
