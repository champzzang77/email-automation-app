01
배경 및 목적
문제 상황

교육운영1팀은 매일 다수의 기업 HR 담당자로부터 교육 신청·변경·취소 메일을 수신합니다. 기존에는 담당자가 Hunet 사내 메일을 수동으로 열어 메일을 하나씩 확인하고, 유형을 판단한 뒤 수작업으로 답변을 작성하는 방식으로 업무를 처리했습니다.

이 과정에서 누락·지연이 발생하고, 반복적인 답변 작업에 불필요한 시간이 소요되는 문제가 있었습니다.

목적
  • Hunet 사내 메일을 자동으로 수집하여 대시보드에서 한눈에 관리
  • 메일 유형(신청/변경/취소/기타)을 키워드 기반으로 자동 분류
  • 분류 결과에 따라 맞춤 답변 템플릿 자동 생성 및 발송
  • 처리 현황을 실시간 KPI로 시각화하여 업무 효율 측정

04
핵심 기능 명세
4-1. 메일 수집
  • "메일 가져오기" 버튼 클릭 시 Playwright로 Hunet 부서메일함 자동 접속
  • 대상 폴더: 부서메일(edulab, edu, aca) > 교육운영1팀(acaedu1, aca1) > 박차민
  • 최대 200건(기본값) 수집, --limit 옵션으로 조정 가능
  • API 응답 캡처 방식 우선, 실패 시 DOM 파싱으로 fallback
  • 페이지네이션 자동 처리 (80건/페이지 기준)
  • 수집 결과를 .mail-output/*.json에 저장
  • JSON 파일 직접 불러오기(📂 JSON) 지원
4-2. 자동 분류
  • 제목 + 본문 키워드 기반 유형 분류 (신뢰도 0~1 점수 산출)
  • 분류 유형: 교육 신청 / 교육 변경 / 교육 취소 / 기타 / 검토 필요
  • 신뢰도 70% 미만은 "검토 필요"로 자동 지정
  • 수동으로 유형 변경 가능 (드롭다운)
  • 설정 > 분류 규칙에서 키워드 추가/삭제 가능
  • Claude AI API 키 입력 시 AI 분류 모드 전환 가능 (선택)
4-3. 메일 처리 상태 관리
미처리
답변 대기
처리완료
답변완료
  • 각 메일은 위 4가지 상태 중 하나로 관리
  • 상태는 localStorage에 저장, 새로고침 후에도 유지
  • "↩ 미처리로 되돌리기" 기능 제공
  • 봉투 아이콘으로 실제 메일함 읽음처리 여부 표시 (📬→📭)
4-4. 답변 관리
  • 유형별 답변 템플릿 자동 적용 ({{이름}}, {{교육명}} 변수 지원)
  • 발송 전 미리보기 팝업에서 내용 수정 가능
  • 검토 후 발송 / 즉시 발송 2가지 모드 지원
  • 답변 대기열: 기본 접힘 상태, "내용 수정" 클릭 시 펼치기
  • 전체 승인 발송 기능
  • 발송 이력 7일 보관
4-5. 실제 메일함 읽음처리
  • Playwright로 Hunet API 호출하여 실제 메일함에서 읽음 처리
  • 대상 폴더 및 sharedFlag 자동 전달 (부서메일 경로 사용)
  • 성공 시 봉투 아이콘 📬 → 📭 변경, localStorage 저장
  • 서버 연결 실패 시에도 앱 내에서 처리완료로 변경 (graceful fallback)
4-6. 대시보드 KPI

4-7. 설정
  • 분류 키워드 규칙 관리 (유형별 추가/삭제)
  • 답변 템플릿 관리 (대기열용 / 처리완료용 분리)
  • 서명 관리 (HTML 편집 + 미리보기)
  • 자동 처리완료 기간 설정 (기본 30일)
  • Claude AI API 키 설정
  • Node.js / Playwright 설치 확인

07
제약사항 및 한계
Hunet은 공식 REST API를 제공하지 않습니다. 모든 메일 수집·발송·읽음처리는 Playwright 브라우저 자동화를 통해 구현되었습니다.
제약사항내용우선순위
로컬 서버 의존성 박차민님 Mac이 켜져 있어야 메일 수집·읽음처리 동작 높음
단일 사용자 현재 다른 PC에서는 API 기능 사용 불가 (UI만 접근 가능) 중간
메일 발신함 없음 Hunet 발신함 API 미제공으로 발송 내역 수신함에서 확인 불가 낮음
세션 만료 Hunet 세션 만료 시 HunetMessenger에서 재로그인 필요 중간
메일 데이터 휘발 새로고침 시 메일 목록이 초기화되어 재수집 필요 중간
